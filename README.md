# Richman — 스마트 금융 통합 플랫폼

> 소비 분석 · 주식 · 크립토를 하나의 흐름으로 연결하고, AI 챗봇이 금융 생활 전반을 해석해주는 스마트 금융 플랫폼
> SSAFY 15기 프로젝트 · Richman 팀 (2026.04 ~ 2026.06)

## 프로젝트 개요

사용자의 소비 데이터와 주식·크립토 시세를 한 곳에서 관리하고, AI가 실제 데이터를 근거로 개인화된 인사이트를 주는 서비스입니다.

```
소비 데이터 수집 → 패턴 분석 → 주식/크립토 조회 → 감성 분석 → AI 챗봇 인사이트
```

| 영역 | 주요 기능 |
| --- | --- |
| 소비 분석 | 소비 캘린더, 카테고리별 분석·AI 리포트, N빵 정산 |
| 주식 | 종목 검색·자동완성, 기술적 지표 차트, 관심 종목·포트폴리오, AI 주가 예측 |
| 크립토 | Upbit 실시간 시세, Social Buzz 지표, 뉴스 감성 분석 |
| AI 챗봇 | 소비·주식·크립토 데이터를 컨텍스트로 주입한 통합 챗봇 |

## 담당 파트 (공병우)

**주식 도메인 전체(백엔드 `backend/stocks`·`backend/portfolio` + 프론트 주식 화면)를 전담**했고, 메인페이지 대시보드와 챗봇의 주식 응답을 맡았습니다.
커밋 기준 40개 (전체 138개 중), 약 +8,800 / −1,700 라인입니다.

| 주식 대시보드 | 국내/미국 탭, 시가총액 상위 종목 실시간 조회(10초 폴링), 더보기 |

### AI 주가 예측

이동평균 가중 평균으로 다음 거래일 가격을 예측하고, 생성형 AI가 해설 코멘트를 붙입니다.

```python
predicted_price = MA5 * 0.6 + MA20 * 0.4   # 단기 추세에 더 높은 가중치
```

- 예측 결과를 DB에 저장하고, 예측일이 지나면 실제 종가와 비교해 정확도를 공개
- OpenAI(SSAFY GMS 엔드포인트)로 2~3문장 코멘트를 생성, 투자 주의 문구를 반드시 포함하도록 프롬프트 설계

### 그 밖의 작업

- **메인페이지**: 삼성전자·BTC 추이 카드, 주식/크립토 실시간 시세 섹션, 대시보드 개편
- **챗봇 주식 응답**: 종목 시세·지표를 컨텍스트로 넣는 `stocks/services/chat_stock.py`, 통합 챗봇 고도화
- **성능**: 여러 종목 시세 조회를 `ThreadPoolExecutor` 로 병렬화해 대시보드 응답 속도 개선
- **공통 UI**: 내비게이션 바, 마이페이지 포트폴리오 탭, 유튜브 금융 콘텐츠 화면
